# NovaKit - Site de vente de produits digitaux

Ce dépôt contient une landing page moderne pour une boutique de produits numériques :

- hero section premium
- catalogue de produits
a- boutons d'ajout au panier
- panier latéral interactif
- section avantages + FAQ
- responsive design pour mobile et desktop

## Démarrage

Ouvrez simplement le fichier `index.html` dans votre navigateur.

## Structure

- `index.html` : structure de la page
- `styles.css` : design complet
- `script.js` : logique du catalogue et du panier

## Personnalisation

Tu peux modifier facilement :
- les textes,
- les prix,
- les produits dans `script.js`,
- les couleurs dans `styles.css`.

## Objectif

Ce modèle est prêt à servir de base pour un site de vente de produits digitaux avec look premium et conversion orientée.
